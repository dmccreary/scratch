# Motion & Coordinates

## Summary

This chapter covers the coordinate plane, the origin point, and how x and y coordinates describe a sprite's absolute position on the stage. Students learn sprite heading, degrees of turn, and the core motion blocks that move and reorient a sprite, including the difference between absolute position and relative movement. This chapter builds on the scripting skills from Chapters 2 and 3 and lays the groundwork for all later drawing work. After completing this chapter, students will be able to position and orient a sprite precisely using motion blocks.
