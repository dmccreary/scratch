# Custom Blocks & Abstraction

## Summary

This chapter centers on Scratch's Make a Block feature as an introduction to procedural abstraction, covering block definitions, naming, calling, and the single-responsibility principle for well-designed blocks. Students build reusable procedures such as a Draw Square block and a Draw Polygon block, compose them into a small block library, and practice refactoring existing scripts into custom blocks. It builds on the computational thinking ideas from Chapter 1, the scripting foundation from Chapter 3, and the drawing work from Chapter 6. After completing this chapter, students will be able to design, name, and reuse their own custom blocks instead of repeating code.
