# The Scratch Interface & Environment

## Summary

This chapter orients students to the Scratch editor itself, including the stage, sprites, costumes, backdrops, the block palette, and the script area. Students learn to identify the eight block categories used throughout the course and how the green flag starts a project. This chapter builds on the computational thinking vocabulary from Chapter 1 by giving students a concrete environment in which to apply it. After completing this chapter, students will be able to navigate the Scratch editor confidently and locate any block category they need.
