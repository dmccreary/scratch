    Mascot Image Prompts: Cody the CoderDojo Turtle¶

    These prompts regenerate Cody's seven poses with a text-to-image model. Each one is self-contained — the full character description is repeated in every prompt, so you can paste any single prompt on its own without copying a separate base block.

    Before using any of them, read character-sheet.md. The character sheet is the source of truth; these prompts must stay in sync with it.

    The committed artwork is a coordinated AI-generated set

    The PNGs currently in this directory were generated from these prompts in one session. The neutral image was used as the visual identity reference for the other six poses, then every result was normalized to the shared 400 × 392 transparent canvas. Regenerate all seven together to preserve consistency.

    Opening instruction to the image model¶

    I am about to ask you to generate seven different poses for a book mascot. Please use a consistent drawing style for all seven images.

    1. Neutral¶

    Please generate a new neutral pose for Cody the Turtle.

A flat vector cartoon illustration of Cody the Turtle, a friendly pedagogical
mascot for an elementary-school (grades 3-5) textbook about computational
thinking with Scratch. Cody is a chunky, upright, kid-friendly turtle with
leaf-green skin (#8BC34A) outlined in darker green (#55892C), and a round
CoderDojo-purple shell (#642580) whose light-purple plates (#8E44AD) are each
rimmed in teal (#41BAC1), over a cream belly plate (#FBEFC8). Cody has large
round white eyes with dark pupils and a white sparkle highlight, soft pink blush
cheeks, and a gentle closed smile. Cody holds a teal marker pen (#41BAC1) with a
dark nib in one hand. Short arms and legs, chunky proportions, readable at 90
pixels. Style: flat vector cartoon, thick rounded outlines, no gradients, no
shadows, no text in the image. Rounded shapes only, no fangs, claws, or spikes.

Cody stands upright in a relaxed, neutral pose facing the viewer directly, with a
calm and friendly closed-mouth smile. Both arms rest naturally at their sides
with no specific gesture, the marker pen held in the right hand. The pose is
balanced and unassuming, suitable as a general-purpose illustration.

Filename: neutral.png

Please generate a new RGBA PNG image now with a fully transparent alpha-channel
background. The background MUST be fully transparent with an alpha channel. DO
NOT use a white, black, or checkered background.

    After generating¶

    Save each file into docs/img/mascot/ using the filename given in its prompt, then trim the transparent padding that image models add:

    python3 ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/neutral.png
python3 ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/welcome.png
python3 ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/thinking.png
python3 ~/Documents/ws/claude-skills/src/image-utils/trim-padding-from-image.py docs/img/mascot/tip.png
